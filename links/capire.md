# Capire Docs & Samples

This agent provides links to the official Capire documentation and sample projects for reference.

## For agents

- [llms.txt](https://cap.cloud.sap/llms.txt) — curated, link-annotated index of the whole doc site; start here to navigate.
- [llms-full.txt](https://cap.cloud.sap/docs/llms-full.txt) — full doc content inlined into one file (~3.5 MB; bulk/offline ingestion only).
- [sitemap.md](https://cap.cloud.sap/docs/sitemap.md) — full semantic sitemap.
- **Markdown of any page:** append `.md` to any docs URL (e.g. `.../docs/get-started/bookshop.md`), or send `Accept: text/markdown`.
